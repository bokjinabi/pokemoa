# GS25 실재고 연동 — 로그인 세션 발급 안내 (2026-11-19 확인)

포켓몬카드모아 중계 서버(`relay/server.js`)가 **GS25(우리동네GS) 매장별 실재고**를 조회하려면
GS가 정상 네이버 로그인 뒤 발급하는 **GS 토큰**(access·refresh·deviceId)이 필요합니다.
CU·세븐일레븐·이마트24는 로그인 없이 동작하므로 **GS25만 이 절차가 필요합니다.**

- 상품 검색(인증 불필요): `POST https://b2c-apigw.woodongs.com/search/v3/totalSearch` — 이미 동작 확인
- 매장별 수량(인증 필요): `GET https://b2c-bff.woodongs.com/api/bff/v2/store/stock`
- 토큰 재발급: `POST https://b2c-bff.woodongs.com/api/bff/v4/auth/tokenReissue` (헤더 `Refresh: <refresh>`)

---

## 0. 준비물

| 항목 | 내용 |
| --- | --- |
| GS25 계정 | 정상 **네이버 로그인**으로 우리동네GS에 들어갈 수 있는 네이버 계정 |
| 실행 환경 | **PC(Windows·macOS·리눅스)** — 화면이 보이는 Chrome 창이 떠야 로그인을 직접 할 수 있습니다 |
| 중계 서버 | `relay/gs25-login.py`(권장) 또는 `relay/gs25-ticket.js` + `relay/gs25-capture.js` |

> 안드로이드 태블릿만으로는 마지막 GS 코드 교환 단계를 할 수 없습니다.
> **PC에서 세션 파일을 만들어 태블릿으로 복사**하는 방식이 가장 간단합니다.

### 방법 A — 스크립트로 한 번에 (권장)

```bash
pip install playwright
python -m playwright install chromium      # 이미 Chrome이 있으면 "--channel chrome" 으로 생략 가능
python relay/gs25-login.py --out gs25-session.json
#   Chrome이 이미 설치된 PC:  python relay/gs25-login.py --channel chrome
```

- 창이 열리면 **네이버 로그인만** 하면 됩니다(필요하면 추가 인증).
- 스크립트가 티켓 발급 → 우리동네GS 채널 이동 → 코드 교환 → 토큰 저장을 대신합니다.
- 토큰은 화면에 찍히지 않고 `gs25-session.json`(0600) 으로만 저장됩니다.
- 2026-11-19 이 환경에서 **티켓 발급·채널 이동·네이버 화면(`우리동네GS 로그인 중`)까지 실행 확인**했습니다
  (마지막 로그인·토큰 저장은 계정 입력이 필요해 미실행).

### 방법 B — 브라우저 콘솔로 직접 (스크립트를 못 쓰는 환경)

아래 1~7단계를 순서대로 하면 됩니다. 개발자 도구(F12) 콘솔이 필요합니다.

---

## 1. 1회용 티켓과 시작 주소 만들기 (터미널)

```bash
node relay/gs25-ticket.js --out gs25-ticket.json
```

출력 예:

```json
{ "ok": true, "deviceId": "7f3f…", "expiresInSec": 600,
  "url": "https://ex-hubpage.grm.gsretail.com/bizmgt/signin/bridge?grmSysCdDtl=2011&page=NAVER&return=…&ticket=…",
  "out": "gs25-ticket.json" }
```

- `deviceId` 는 세션에 반드시 같이 저장해야 합니다(`--out` 파일에 남습니다).
- 티켓은 **10분·1회용**입니다. 만료되면 이 명령을 다시 실행하세요.
- `url` 은 GS가 발급한 1회용 티켓이 들어 있는 주소이며, 계정을 여는 값이 아닙니다.

## 2. 브라우저에서 GS 채널 초기화

1. 출력된 `url` 을 Chrome에서 엽니다. (`GS ALL 멤버십` 화면이 뜹니다)
2. `네이버와 잠시 통신 장애가 발생하였습니다` 팝업이 뜨면 **확인**을 누릅니다. (정상 동작입니다)
3. 화면에 `닫기` 버튼 하나만 남습니다. **이 화면에서 멈추고 다음 단계로 갑니다.**
   - 여기서 `/bizmgt/signin/bridge/naver` 주소를 직접 열면 **GS SHOP 채널**로 로그인되어
     우리동네GS 재고 토큰이 나오지 않습니다(2026-11-19 실측: 네이버 화면에 `GS SHOP 로그인 중` 표시).
     반드시 아래처럼 **현재 페이지의 라우터로 이동**해야 `우리동네GS` 채널이 됩니다.

## 3. 같은 탭의 콘솔(F12)에서 채널 이동

```javascript
(async () => {
  if (location.origin !== 'https://ex-hubpage.grm.gsretail.com') return console.log('GS 허브 페이지에서 실행하세요.');
  const router = document.querySelector('#__nuxt')?.__vue_app__?.config.globalProperties.$router;
  if (!router) return console.log('GS 앱 초기화가 끝났는지 확인하세요.');
  await router.push('/bizmgt/signin/bridge/naver');
})();
```

네이버 로그인 화면이 열리면 제목이 **`우리동네GS 로그인 중`** 인지 확인합니다.
(`GS SHOP 로그인 중`이면 1단계부터 새 티켓으로 다시. 2026-11-19 실측: 채널별 네이버 client_id 가 다릅니다 —
우리동네GS `VFjv3tsLofatP90P1a5H`, GS SHOP `lKFdFcYB3_zG0kl3EjH6`.)

## 4. 네이버 로그인

아이디·비밀번호(또는 QR 로그인)로 로그인하고 추가 인증이 있으면 마칩니다.
로그인 직후 GS 허브 탭으로 돌아오며 주소가 `…/bizmgt/signin/bridge/naver?code=…&state=…`
형태가 되거나, `닫기` 화면에 멈춥니다.

## 5. GS 코드 교환 (닫기 화면에 멈췄을 때)

같은 GS 탭의 콘솔에서 **한 번만** 실행합니다. (`code`/`state`는 일회용 승인 정보이며 GS 토큰이 아닙니다)

```javascript
(async () => {
  if (location.origin !== 'https://ex-hubpage.grm.gsretail.com' || location.pathname !== '/bizmgt/signin/bridge/naver')
    return console.log('네이버 로그인 후 돌아온 GS 허브 탭에서 실행하세요.');
  const p = new URLSearchParams(location.search);
  const codes = p.getAll('code'), states = p.getAll('state');
  if (codes.length !== 1 || states.length !== 1) return console.log('승인 정보가 없습니다. 새 티켓으로 다시 로그인하세요.');
  const nuxt = document.querySelector('#__nuxt')?.__vue_app__?.config.globalProperties.$nuxt;
  const modulePath = '/_nuxt/login.CDygB59Y.js';   // 2026-11-19 확인값 (배포마다 바뀔 수 있음)
  const exportName = 'u';
  try {
    const mod = await import(modulePath);
    const api = nuxt.runWithContext(() => mod[exportName]());
    const r = await nuxt.runWithContext(() => api.loginNaver({ code: codes[0], state: states[0] }));
    console.log(r === 'ERROR' ? '교환 실패 — Network에서 상태 코드만 확인하세요.' : '교환 호출 완료');
  } catch (e) { console.log('교환 실패 — 모듈 경로/앱 컨텍스트를 확인하세요.'); }
})();
```

- 요청: `POST /api/hub/bridge/v2/login/naver` (Network 탭에서 `login/naver` 필터로 확인)
- **모듈 경로가 바뀌었을 때**: DevTools → Sources → 전체 검색(Ctrl+Shift+F)에서 `loginNaver` 또는
  `/api/hub/bridge/v2/login/naver` 를 찾아 그 파일의 `/_nuxt/…js` 경로와 export 이름을 확인합니다.
  (2026-10-06: `login.BDscyujx.js` → 2026-11-19: `login.CDygB59Y.js`, export 는 계속 `u`)

## 6. GS 반환 주소 → 세션 파일

성공하면 브라우저가 아래 주소로 이동합니다.

```
https://b2c-bff.woodongs.com/api/bff/v4/grmHub/authReturn?result=Y&resultCode=0000&token=<access>&refresh=<refresh>…
```

그 주소를 복사해 터미널로 넘깁니다. **토큰은 화면에 다시 찍히지 않습니다.**

```bash
node relay/gs25-capture.js --device <1단계 deviceId> --out gs25-session.json
# 실행 후 authReturn 주소를 붙여넣고 Enter
```

- 성공 출력: `{"authenticated":true,"file":"gs25-session.json","accessExpiresAt":"…","refreshExpiresAt":"…"}`
- 파일 권한은 `0600`, 내용은 `{accessToken, refreshToken, deviceId}` 세 값뿐입니다.
- 기존 파일이 있으면 `gs25-session.json.prev` 로 백업합니다(회전된 refresh 를 잃지 않도록).

## 7. 중계 서버에 세션 넣기

가장 간단한 방법: **`gs25-session.json` 을 `server.js` 옆(같은 폴더)에 두고 그냥 실행**하면 됩니다.

```bash
node server.js          # 같은 폴더의 gs25-session.json 을 자동으로 읽습니다
```

다른 위치에 두려면:

```bash
GS25_SESSION_FILE=/절대경로/gs25-session.json PORT=3100 node server.js
```

또는 토큰을 환경 변수로 직접:

```bash
GS25_ACCESS_TOKEN=… GS25_REFRESH_TOKEN=… GS25_DEVICE_ID=… PORT=3100 node server.js
```

확인:

```bash
curl -s "http://127.0.0.1:3100/api/gs25?lat=36.0733&lng=129.3947" | head -c 600
```

`session.configured: true`, `products`에 상품 목록, `stores`에 매장별 수량이 오면 성공입니다.
실패 시 `note` 에 이유가 적힙니다.

- access 토큰은 약 24시간, refresh 는 약 90일입니다. 중계 서버가 **만료 1분 전**과 **재고 401/403** 때
  `tokenReissue` 로 자동 갱신하고, `GS25_SESSION_FILE` 을 쓰면 회전된 토큰을 파일에 되씁니다.
- refresh 까지 거절되면(예: `9914 Refresh token error`) 다시 3~6단계로 세션을 새로 발급하고
  **중계 서버를 재시작**해야 합니다(메모리에 든 옛 세션을 계속 쓰기 때문).
- 참고: 재발급 응답은 오류일 때 `reqParams.Refresh` 에 refresh 토큰 일부를 되돌려 줍니다.
  중계 서버는 응답 본문과 진단 출력에서 JWT·Bearer·Refresh 값을 `…<가림>` 으로 지웁니다.

| CU 매장별 수량 | **확인** — 로그인 없이 `storeList[].stock` 실제 수량(예: 신라면 26·28·20…, 카드 0) |
